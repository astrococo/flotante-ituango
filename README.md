# Material Flotante Ituango

**Aplicación:** https://astrococo.github.io/flotante-ituango/

Pronóstico y seguimiento de la extracción de material flotante y macrófitas en la cola del embalse del Proyecto Hidroeléctrico Ituango, con los caudales del río Cauca de [HydroForecast Ituango](https://astrococo.github.io/hydroforecast-ituango/).

Este repositorio público solo publica la página y datos de fuentes públicas:

- `index.html`, `app.js`, `sw.js`, `vendor/`: la página (se copian cada hora desde el código, tarea `sitio`).
- `datos/satelite/`: vegetación flotante con Sentinel-2, Landsat, Sentinel-1 y NASA Earthdata.
- `datos/lluvia/` (CHIRPS) y `datos/ideam/` (caudales públicos del IDEAM).

El código y los registros de extracción están en un repositorio privado. La página pide un token de lectura para mostrarlos; solicítelo al administrador.
